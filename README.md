# 🏆 2026 토익스피킹 실전 CBT 마스터 트레이너 (Apple Liquid Glass Edition)

2026 최신 토익스피킹 시험(Part 1 ~ Part 5, 총 92문항 & 187개 만능 문장) 완벽 대비용 인터랙티브 실전 CBT 웹 트레이너입니다.
실제 시험 환경 시뮬레이션, 음성 재생(Daniel 영국 표준 발음), 배속 조절(1.0x / 0.75x 쉐도잉), 문장별 분할 학습 및 애플 리퀴드 글래스(Liquid Glass) 기반의 미려한 반응형 UI/UX를 제공합니다.

## 🚀 주요 기능 및 특징

### 1. 📚 파트 1 ~ 파트 5 전 파트 실전 기출 (총 92문항)
- **Part 1 (Q1~Q2)**: 지문 읽기 (전체 지문 원문 노출 + 하단 문장별 분할 쉐도잉 & 개별 발음)
- **Part 2 (Q3~Q4)**: 사진 묘사하기 (26개 고화질 실사 시험 사진 레터박스 없는 최적 비율 탑재, 제니 4단계 공식 모범답안)
- **Part 3 (Q5~Q7)**: 일상 질문 답하기 (30문항 대규모 보충, 상황별 실전 질의응답)
- **Part 4 (Q8~Q10)**: 표 분석 및 듣기 (표 유형별 분류 및 연계 문제, 듣기 전용 '질문듣기' 우선 모드 + '질문 지문 보기' 토글)
- **Part 5 (Q11)**: 의견 제시하기 (최신 비즈니스/일상 찬반 및 해결책 제시 실전 문항)

### 2. 💎 Apple Liquid Glass 반응형 UI & UX
- 애플 웹사이트 스타일의 반투명 블러(Backdrop blur)와 유려한 리퀴드 글래스 스타일 적용.
- 모바일(스마트폰), 태블릿(아이패드 등), 데스크탑 모든 기기 화면에 최적화된 반응형 레이아웃.
- 좌측 상단 원클릭 **다크모드 스위치 토글**로 주간/야간 최적의 시인성 제공.
- 우측 상단 원클릭 **단어장 모달** (제니 187 만능 문장 & 핵심 어휘 및 발음기호 탑재).

### 3. 🎧 Daniel 전담 영국식 음성 & 유연한 발음 학습 제어
- 명료하고 신뢰감 있는 영국식 표준 발음 `Daniel` 보이스 기본 탑재.
- **선택 재생 방식**: 듣고 싶은 모범답안 문장이나 단어 카드를 클릭하여 선택한 후, 하단 제어바에서 **1.0x(보통)** 또는 **0.75x(쉐도잉 느린 속도)**를 선택하여 학습.
- **재생 중 즉시 정지**: 하단 정지 버튼으로 언제든지 음성 즉각 제어.
- 파트 4는 실전 듣기 평가 원칙에 맞추어 지문은 숨긴 채 먼저 음성을 듣고 확인할 수 있도록 구현.

### 4. ⏱️ 실제 CBT 시험장 타이머 & 모범답안 토글
- 준비 시간 및 답변 시간 초 카운트다운 타이머 탑재.
- 실전 시험 긴장감을 유지할 수 있도록 모범답안 및 해석은 기본적으로 숨겨져 있으며, 버튼 클릭 시 확인 가능.

## 💻 로컬 개발 환경 실행 (React + Vite + TypeScript)

소스코드를 수정하거나 빌드하려면 아래 명령어를 사용하세요:

```bash
# 1. 의존성 패키지 설치
npm install

# 2. 로컬 개발 서버 실행
npm run dev

# 3. 배포용 빌드
npm run build

# 4. 최신 독립형 toeicspk_cbt2026.html 단일 파일 재생성
python3 scripts/generate_standalone_html.py
```
